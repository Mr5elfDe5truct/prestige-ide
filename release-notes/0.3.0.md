## Prestige IDE 0.3.0 · See what it's doing

**New**
- **Working readout** next to the send button while the agent works, the same one Prestige 0.60.0 has. The red diamond pulses inside a turning gold ring, and next to it you see:
  - the **model** doing the work, or "subagent · model" while a subagent runs;
  - the **tool** it's calling, in a red tag (read_file, edit_file, run_command, grep, task…). The ring turns red and spins faster while a tool runs;
  - **what it's doing**, in words: Waiting for the model, Thinking, Writing, Edit src/main.ts, Run npm test, Waiting for your approval, Reading the results, Compacting the conversation. During a subagent it follows each of the subagent's own steps;
  - how long the task has been running.
- **Tool cards** say which model called them ("by Qwen3.8-27B"), and the running one glows gold along its head until it's done.
- The plain "Working…" text is gone; the status line now only shows messages such as hook warnings.

**Good to know**
- Scheduled runs and the benchmark run without the readout, as before.
- The animations stop when Windows has "Show animations" turned off.
