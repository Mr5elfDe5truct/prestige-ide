## Prestige IDE 0.4.0 · Cloud models (optional)

**New**
- **Custom API** in Settings: an OpenAI-compatible address and key, such as Google AI Studio for Gemini (`https://generativelanguage.googleapis.com/v1beta/openai`), Groq (`https://api.groq.com/openai/v1`) or OpenRouter (`https://openrouter.ai/api/v1`). Its chat models join the model picker and the tiers. Gemini models get friendly names.
  - Each model's context size and whether it reads pictures come from the service's model list when it gives them (OpenRouter, Groq). Gemini models get 1M tokens. Others get 128k. Auto-compact starts at the right point.
  - You can switch a conversation from a local model to Gemini partway through. Earlier tool calls that Gemini didn't make are passed to it as text, because it rejects tool calls without its own signature.
  - A **Cloud** dot joins Ollama, llama.cpp and Tools in the sidebar, and an error points you to the address and key instead of the Workstation.

**Good to know**
- It's off until you fill in the address. Leave it empty and the IDE stays fully local.
- With it on, your prompts and the code the agent reads go to that service.
- The key is saved in the IDE's settings file on this PC (`%APPDATA%\com.rgstudios.prestige-ide`).
- The app's own requests can now reach HTTPS addresses (needed for any service you enter). The page inside the window still can't: only the IDE's backend makes those calls.
