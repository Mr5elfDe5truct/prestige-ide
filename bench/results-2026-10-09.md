## Notes

- One run per model and task, so a difference of one task between models is within noise. The time differences are not.
- Thinking models timed out on t02 the same way: they fixed the bug early, then spent the rest of the 20 minutes
  rewriting the filter to remove a harmless leading space their own extra tests flagged.
- The harness put each task's folder next to the others. HauhauCS read a neighbouring task's copy of the file during
  t02 (a run it failed); no passing run read outside its own folder. Later runs give each task its own temporary folder.
- NEO-CODER's llama.cpp process exited while loading (likely its MTP draft head); testing stopped before that was
  looked into, so it has no score.
- Reference PC: RTX 3060 12 GB + RTX 2060 6 GB, 32 GB RAM. The 35B ran with 27 of 40 expert layers in system RAM at
  128k context; the 27Bs were split across both cards at 32k.
